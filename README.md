# NovaTech Systems — Enterprise Tech Website

NovaTech Systems is a concept enterprise-tech website created to demonstrate product storytelling, responsive UI design, interactive comparison tools, case-study modals, global search, and investor-resource presentation.

> This is a concept portfolio project, not a representation of a real NovaTech client engagement.

## Features

- Responsive enterprise technology website experience
- Interactive Atlas Core, Vector AI, and Sentinel Grid product overview
- Product capability comparison matrix
- Case-study carousel with expandable detail modals
- Multi-author insights hub with category filtering
- Investor and press center with downloadable PDF and ZIP reports
- Global search across products, case studies, insights, and resources
- Desktop, tablet, and mobile layouts

## Built with

- React
- TypeScript
- Vite
- Tailwind CSS
- Wouter
- Lucide React
- Responsive CSS

## Local development

Install the pinned dependencies and start the static development server:

```bash
pnpm install --frozen-lockfile
pnpm dev:static
```

The development server runs on port `3000` by default.

Useful commands:

```bash
pnpm check          # TypeScript diagnostics
pnpm build:static   # Production static build
pnpm test           # Application tests
```

## Project structure

- `client/src/pages/Home.tsx` — NovaTech landing page and interactions
- `client/src/index.css` — visual system, responsive layout, and components
- `client/public/reports/` — downloadable investor and press resources
- `client/public/manus-routes.json` — published page route manifest

## Portfolio context

The project was designed as a polished enterprise-tech portfolio piece to showcase frontend development, product UX, responsive design, interaction design, and presentation of complex B2B product narratives.
